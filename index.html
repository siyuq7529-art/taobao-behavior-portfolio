我做了什么

  1. 使用 Python 抽取 20 万条行为记录，导入 MySQL 后检查缺失值、重复记录和时间范围，剔除 92 条范围外记录。
  2. 按日期、小时和行为类型汇总事件次数，再按类目分别比较浏览量和购买量。对比样本发现，浏览量最高的类目与购买量最高的类目不同。
  3. 将查询结果整理到 Excel，再用 Power BI 制作行为分布、分时趋势和类目表现看板，最后写成分析报告。

MySQL 查询示例

把时间戳转成小时后，以小时和行为类型分组，统计的是事件次数。

SELECT HOUR(FROM_UNIXTIME(ts)) AS event_hour,
       behavior_type, COUNT(*) AS event_count
FROM user_behavior_clean
GROUP BY event_hour, behavior_type
ORDER BY event_hour, behavior_type;
查看同用户、同商品的加购路径修订示例

用用户 ID、商品 ID 和时间顺序约束三个事件，按用户去重。此处展示修订写法，尚未用修订后的脚本重算转化率。

SELECT COUNT(DISTINCT p.user_id) AS users
FROM user_behavior_clean AS p
JOIN user_behavior_clean AS c
  ON c.user_id = p.user_id AND c.item_id = p.item_id
 AND c.ts > p.ts AND c.behavior_type = 'cart'
JOIN user_behavior_clean AS b
  ON b.user_id = c.user_id AND b.item_id = c.item_id
 AND b.ts > c.ts AND b.behavior_type = 'buy'
WHERE p.behavior_type = 'pv';

从结论到业务问题

样本中浏览和购买次数均在 21 时最高，加购和收藏均在 22 时最高。可以把晚间作为商品展示的候选时段，并用更多日期验证这一规律。对浏览量高、购买量低的类目，可以进一步核查商品结构、价格和页面表现。该分析使用抽样记录，结果反映样本中的行为分布。
